# Bathynomus

Bathynomus is currently in alpha development. Currently it is only a prototype, however we are hoping to have a minimum
viable product in early 2027.

## What is Bathynomus?

Bathynomus is an open source quality assurance tool.

## Features

The main planned features for Bathynomus are;

* Create projects
* Create requirements
* Create test cases
* Create test plans
* Create test runs
* Create reports from test runs
* Create issues/bugs

We are currently under active development and are hoping to have a minimum viable product in early 2027.
